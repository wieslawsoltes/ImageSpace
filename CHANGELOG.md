# Changelog

## 0.1.0-alpha.1 — 2026-09-27

Initial independent Uno desktop/browser image editor.

- Eleven reusable .NET libraries covering the tiled model, brushes/selections, filters, transactions, archives/PSD, Skia, WebGPU, storage, custom controls, viewport and workbench.
- Original layered sample artwork and Photoshop-style dark workspace.
- Pixel painting, selections/masks, transforms/crop, editable type/shapes, blend/opacity and history.
- Bounded native and PSD interchange, raster import/export and local recovery.
- Browser WebGPU color kernels with CPU fallback and device-loss handling.
- Model/compositor regressions, browser pointer/keyboard/file/rendered-pixel acceptance, desktop build matrix and verified Pages publishing.

This is an initial functional release, not full Photoshop parity. Unsupported features and file-preservation limitations are tracked in `docs/features.md`.
